### Projetos em destaque

- **[Financial Sample — Pipeline Medalhão](https://github.com/mAcosOS-banana/financial-sample-medallion-pipeline):** pipeline de dados em arquitetura medalhão (Raw → Bronze → Silver → Gold), com ingestão em Python e Polars, transformações em PostgreSQL, modelagem dimensional em esquema estrela e relatórios em Power BI com DAX.
- **[Financial Controller App](https://github.com/mAcosOS-banana/financial_controller_app):** API REST para planejamento financeiro compartilhado, desenvolvida em Flask com arquitetura em camadas, autenticação JWT, validação com Pydantic e testes automatizados com pytest. Front-end em React em desenvolvimento.
