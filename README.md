## 📂 Projetos em destaque

### 🥇 [Financial Sample — Pipeline Medalhão](https://github.com/mAcosOS-banana/financial-sample-medallion-pipeline)
Pipeline em camadas **raw → bronze → silver → gold** com o dataset Financial Sample.
- Ingestão com **Polars**
- Transformações em **SQL** no **PostgreSQL** (hospedado no Render)
- Consumo em **Power BI**

### 💰 API de Planejamento Financeiro Compartilhado
API REST para planejamentos financeiros entre várias pessoas.
- **Flask + SQLAlchemy + Pydantic v2 + PostgreSQL**
- Autenticação com **JWT** e senhas com **bcrypt**
- Arquitetura em camadas: routes, services, models, DTOs e middlewares
- Soft delete, envelope de resposta padronizado e hierarquia de exceções com handlers globais
- Testes com **pytest**

### 🐳 DockerLearning
Projeto de estudo com containers.
- App **Streamlit** em Dockerfile, gerenciado com **uv**
- **PostgreSQL 16 + pgAdmin** no docker-compose
- Acesso ao banco com **psycopg2** e processamento com **Polars**
